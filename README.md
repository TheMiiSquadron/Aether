# Aether

**Local-first infrastructure for personal AI across trusted devices.**

Aether is a local-first platform that allows a personal AI to exist securely across a trusted constellation of devices.

It provides common infrastructure for device identity, discovery, trust, communication, capabilities, presence, and coordination while remaining independent of any particular AI identity, model, interface, or operating system.

## Project Status

Aether is currently in early development.

The initial development target is **Aether Foundation v0.1**, establishing the architecture, device model, security boundaries, Constellation, and core protocol before higher-level integrations are built.

## Design Principles

- Local-first
- User-controlled
- Platform-independent
- AI-independent
- Secure by default
- Explicit trust between devices
- No unrestricted remote control
- Network access does not imply trust
